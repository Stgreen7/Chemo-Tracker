Install as an app

On Android, install this so it opens as its own icon, full-screen, and keeps working with no internet connection at all — nothing about your data changes, it's still only on this device.

Don't see the button? In Chrome, tap the ⋮ menu (top right) → Add to Home screen / Install app.

Notifications

This tab can pop a reminder when a dose is due, but only while this browser tab is open — it can't wake your phone in the background. For that you'd need this installed as a proper app.
